# Profils de jeux

Un fichier par jeu, décrivant ses cas particuliers : dossier inhabituel, version de loader imposée, anti-triche connu.

Les profils sont de la **donnée pure** : ils ne contiennent ni n'exécutent jamais de code (voir `SPEC.md`, sections 6.3 et 7). Le format sera fixé avec la brique `games` du moteur.
